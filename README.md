## 交易所邀请码是什么？对谁有好处？

交易所邀请码（也叫推荐码、推荐 ID、Referral Code）是一串字母或数字，用来标记「你是通过谁介绍来的」。

机制很简单：交易所希望更多人来注册，于是设计了分成制度——如果 A 介绍 B 来注册，B 之后每次交易付给交易所的手续费，交易所会分一部分出来。

| 角色 | 得到什么 |
|------|---------|
| 被邀请人（你） | 拿到自己所付手续费的一部分回馈，等于变相打折 |
| 邀请人 | 拿到被邀请人手续费的一部分作为佣金 |
| 交易所 | 用一部分手续费收入换来新用户，比投广告便宜 |

关键是要理解：**这笔钱是从交易所本来要收的手续费里分出来的，不是从你口袋里额外掏的。** 填不填邀请码，你付给交易所的手续费总额不变，差别只在于有没有一部分被退回来给你。

## 用别人的邀请码注册有坏处吗？

没有实质坏处。这是新手最常见的顾虑，把常被担心的几点说清楚：

- **不会泄露个人资料。** 邀请人能看到的通常只有「某个 ID 注册成功了」「产生了多少返佣」这类统计，看不到你的姓名、身份证、手机号、邮箱，也看不到你的持仓和资金。
- **不会影响账户权限或安全。** 填码与没填码的账户功能完全一样，KYC 流程、提币额度、可用交易对都不受影响。
- **不会让你多付钱。** 返佣来自交易所本来要收的手续费，不是加价。
- **不会让邀请人碰到你的钱。** 邀请码只是统计标记，不带任何账户操作权限。

任何人如果以「帮你操作」「帮你代管」为理由索要你的密码、验证码、助记词，一律是诈骗，跟邀请码无关。

唯一需要注意的是：**别通过来路不明的链接注册。** 正确做法是自己打开交易所官网或官方 App，在注册页手动输入邀请码——既拿到返佣，又完全避开钓鱼网站风险。

## 邀请码返佣是怎么计算的？

返佣的计算基础是**你实际支付的交易手续费**，不是你的交易金额，也不是你的盈亏。这一点很多新手会搞错。

用币安现货来举例：

| 项目 | 数值 |
|------|------|
| 币安现货基础手续费 | 0.1% |
| 交易金额 | 10,000 USDT |
| 产生的手续费 | 10 USDT |
| 返佣 20% | **2 USDT** |
| 换算成交易额比例 | 仅约 0.02% |

也就是说，返佣是「手续费的百分比」，而不是「交易额的百分比」。10,000 USDT 的交易拿到 2 USDT 返佣，换算成交易额只有 0.02%——所以不要被「最高返佣 20%」的说法误导成「交易能赚 20%」，这两件事完全不同。

## 币安邀请码最高返佣比例是多少？搭配 BNB 能省到多少？

先把两个容易被混为一谈的数字分清楚：

- **返佣比例上限是 20%**，这是币安推荐计划本身的规则，指的是「退还你所付手续费的 20%」。本文的邀请码 `DBRO20OFF` 就是 20% 这一档，也就是官方规则允许的最高档。
- **BNB 抵扣是另一套独立机制**，跟邀请码无关。在币安现货交易中开启 BNB 抵扣，手续费打 7.5 折（也就是省 25%）。

**这两项可以叠加**。用币安现货普通用户费率算一遍：

| 步骤 | 费率 |
|------|------|
| 现货基础手续费 | 0.1% |
| 开启 BNB 抵扣（7.5 折） | 0.075% |
| 再返还已付手续费的 20%（0.075% × 20% = 0.015%） | 实际净付 **0.06%** |

从 0.1% 降到 0.06%，**等于总共省下了 40% 的手续费**。

这里要特别说清楚：**40% 是「两套机制叠加后省下的手续费比例」，不是「返佣比例」**。如果有人告诉你「我的邀请码返佣 40%」或「返佣 45%」，那是把两件事混在一起讲——按币安官方推荐计划规则，返佣比例本身的上限就是 20%。你可以自己去币安官方的推荐计划页面和费率页核对这两个数字。

⚠️ **合约不适用这个 40%**。币安 U 本位合约的 BNB 抵扣只有 **9 折**（省 10%），不是现货的 7.5 折，叠加返佣后约省 28%，跟现货的 40% 是两回事。

另外提醒：BNB 抵扣需要你的账户里持有 BNB 才能生效，而 BNB 本身价格会波动。这不是「白拿」的折扣，是拿一部分资金去持有 BNB 换来的。

## 邀请码和推荐链接有什么区别？

两者达成的效果一样，都是建立邀请关系，区别在于形式和风险：

**推荐链接**是一条完整网址，点进去之后邀请码会自动填好，不用手动输入。方便，但风险在于——你没办法一眼确认这条链接真的是通往交易所官网，钓鱼网站最常用的手法就是伪造一条长得很像的链接。

**邀请码**只是一串字符，需要你自己打开官网、手动输入。多了一个步骤，但安全性高得多，因为网址是你自己输入的，不可能被导去假网站。

**对新手，强烈建议用邀请码而不是点别人的链接。** 这也是本文只提供邀请码、不提供推荐链接的原因。

## 邀请返佣是终身的吗？

不一定，各家规则不同，而且规则会随时间调整，这是最需要你自己去官方页面确认的一项。

常见的几种设计：有效期终身、有效期限定几个月、或者按被邀请人的交易量/VIP 等级动态调整比例。也有交易所会在活动期间临时提高返佣比例，活动结束后回落。

比较可靠的判断方式是登入账户后，在「推荐计划」或「返佣中心」页面查看当前实际生效的比例和规则说明，那里显示的才是你账户上真正在跑的数字。

## 返佣什么时候到账？

- **OKX**：官方口径是**每小时结算**一次返佣。
- **币安**：结算频率以官方推荐计划页面的说明为准，一般是产生手续费后按周期发放。

返佣通常会发到账户内的一个专门位置（常见叫「返佣中心」「推荐奖励」「佣金记录」）。如果交易了却看不到返佣，先确认三件事：邀请关系是否真的绑定成功、这笔交易类型是否属于返佣计划范围（有些活动手续费或特定产品不算）、以及是否还没到结算时间。

## 币安/OKX 怎么查自己有没有绑定邀请码？

登入账户后，找到「推荐」「邀请好友」「返佣中心」这类入口，看两个信号：

1. **页面上有没有显示「邀请人」「推荐人」或对方的部分 ID** —— 有，说明绑定成功。
2. **有没有返佣记录或返佣比例的数据** —— 有产生过交易但完全没有返佣记录，可能就是没绑定。

如果页面只显示「邀请你的好友」这类让你去邀请别人的内容，完全找不到任何「我的邀请人」信息，通常代表你注册时没有填邀请码。这种情况下，OKX 无法补填；币安可以尝试联系客服申请修改，但成功率不确定。
